# ビリ推し 浅色配色设计稿

## 目标

只调整背景与组件表面颜色，不改变现有布局、字号、圆角和交互。四套方案都保留品牌深青 `#2d6763`，并继续用白色卡片承载主要信息。

## 四套方向

| 方案 | 工作区 | 侧栏 / 嵌套底 | 卡片 | 定位 |
| --- | --- | --- | --- | --- |
| 01 纸白 | `#fcfcfb` | `#f5f5f2` | `#ffffff` | 默认推荐。Claude 式中性白，最安静 |
| 02 暖纸白 | `#f6f3ec` | `#efece4` | `#fffdf9` | 更明显的温和纸感，长时间停留舒适 |
| 03 雾青灰 | `#f2f6f5` | `#e9f0ee` | `#fbfdfc` | 更清爽、更统一，适合偏工具感的审美 |
| 04 暖杏灰 | `#f8f0e5` | `#f2e8da` | `#fffaf2` | 陪伴感最强，适合夜间或偏柔和的审美 |

## 为什么默认选纸白

Claude 的浅色界面取样约为 `#fcfcfb`，侧栏和画布几乎没有色相差，主要靠留白、细线和卡片明度建立层级。**纸白**沿用这个思路：背景只比卡片深一点，深青只出现在操作和状态上。

它比暖纸白更中性，不会让白色卡片显得发黄；同时又保留了一点暖底，避免变成冷冰冰的系统灰。推荐顺序：

**纸白 → 暖纸白 → 雾青灰 → 暖杏灰**

如果后续只保留一个默认主题，用纸白；如果准备做主题切换，这四套已经覆盖安静、温和、清爽、柔和四种情绪。

## 为什么还保留暖纸白

暖纸白是上一轮的方向，背景的米色更明确。它适合喜欢纸张感、且主要在室内暖光下使用的用户；但在白色卡片旁边会更容易看出黄色调，所以不作为默认。

## 要改的部件

设计稿的「颜色映射」里有 16 项完整表格。落到代码时只改现有 CSS 变量，不动布局：

| 层级 | 变量 |
| --- | --- |
| 窗口画布、状态条、嵌套增益卡 | `--paper` |
| 侧栏、顶栏 | `--surface-sunk` |
| 卡片、输入框、次级按钮、选中项 | `--surface` |
| 悬停和按下 | `--surface-hover` / 少量硬编码 wash 规则 |
| 主 / 次 / 辅助文字 | `--ink` / `--ink-2` / `--ink-3` |
| 细线 / 控件描边 | `--line` / `--line-strong` |
| 主按钮、开关、进度、选中图标 | `--accent` / `--accent-soft` / `--accent-line` |
| 直播、警告、危险 | `--live*` / `--warn*` / `--danger*` |

品牌 Logo 的深青渐变、二维码白底、窗口关闭按钮的红色悬停保持不变。

## 对比度

按实际文字透明度与背景合成后计算：

| 方案 | 主文字 | 次要文字 | 辅助文字 | 深青按钮白字 |
| --- | --- | --- | --- | --- |
| 纸白 | 16.51:1 | 5.67:1 | 4.96:1 | 6.50:1 |
| 暖纸白 | 15.26:1 | 5.73:1 | 5.01:1 | 6.50:1 |
| 雾青灰 | 14.51:1 | 5.53:1 | 4.85:1 | 6.50:1 |
| 暖杏灰 | 14.40:1 | 5.48:1 | 4.85:1 | 6.50:1 |

辅助文字在纸面上最低 4.67:1，满足小字号文本的 4.5:1 要求。

## 实施状态

- 生产界面已切换到**纸白**表面变量（`desktop/webui/assets/style.css`），并在「设置 › 外观」提供纸白、暖纸白、雾青灰、暖杏灰四套主题即时切换；选择保存在本机 `localStorage`，不写入账号配置。
- 运行模式的原生下拉已替换为自绘菜单；设计稿中的挂机设置页同步展示了新控件。
- 设计稿顶部的方案标签用于并排评审；应用内的实际入口在「设置 › 外观」。

## 预览

- 打开 `Color Study.html`
- 顶部切换四套方案；工具栏切换总览、挂机设置、账号
- 「颜色映射」展开完整色值与组件对应关系
- 「并排比较」同时加载四套配色

设计稿复用当前生产界面的样式与组件，仅新增主题覆盖（`assets/design.css`）与演示数据。
