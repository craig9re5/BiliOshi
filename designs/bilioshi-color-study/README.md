# ビリ推し 浅色配色设计稿

## 目标

只调整背景与组件表面颜色，不改变现有布局、字号、圆角和交互。三套方案都保留品牌深青 `#2d6763`，并继续用暖白卡片承载主要信息。

## 三套方向

| 方案 | 纸面 | 侧栏 / 嵌套底 | 适合 |
| --- | --- | --- | --- |
| 01 暖纸白 | `#f6f3ec` | `#efece4` | 默认推荐。与当前版本最连续，长时间停留不刺眼 |
| 02 雾青灰 | `#f2f6f5` | `#e9f0ee` | 更清爽、更统一，适合偏工具感的审美 |
| 03 暖杏灰 | `#f8f0e5` | `#f2e8da` | 更明显的陪伴感，适合夜间或偏柔和的审美 |

## 为什么是这三套

- **暖纸白**：保留现有“暖纸 + 白卡”的气质，只把背景和嵌套表面拉出一点明度层次。风险最低，也最耐看。
- **雾青灰**：中性色向品牌深青靠拢，减少暖色与深青之间的轻微冲突；视觉更干净、界面边界更清楚。
- **暖杏灰**：暖度明确但不发黄，给人“傍晚室内光”的感觉。它的个性最强，也最依赖环境光线。

推荐顺序：**暖纸白 → 雾青灰 → 暖杏灰**。如果后续只做一个默认主题，建议暖纸白；如果准备做主题切换，这三套已经能覆盖安静、清爽、温和三种情绪。

## 要改的部件

设计稿的「颜色映射」里有 16 项完整表格。落到代码时只改现有 CSS 变量，不动布局：

| 层级 | 变量 |
| --- | --- |
| 窗口画布、状态条、嵌套增益卡 | `--paper` |
| 侧栏、顶栏 | `--surface-sunk` |
| 卡片、输入框、次级按钮、选中项 | `--surface` |
| 悬停和按下 | `--surface-hover` / 少量硬编码 wash 规则 |
| 主 / 次 / 辅助文字 | `--ink` / `--ink-2` / `--ink-3` |
| 细线 / 控件描边 | `--line` / `--line-strong` |
| 主按钮、开关、进度、选中图标 | `--accent` / `--accent-soft` / `--accent-line` |
| 直播、警告、危险 | `--live*` / `--warn*` / `--danger*` |

品牌 Logo 的深青渐变、二维码白底、窗口关闭按钮的红色悬停保持不变。

## 对比度

按实际文字透明度与背景合成后计算：

| 方案 | 主文字 | 次要文字 | 辅助文字 | 深青按钮白字 |
| --- | --- | --- | --- | --- |
| 暖纸白 | 15.26:1 | 5.73:1 | 5.01:1 | 6.50:1 |
| 雾青灰 | 14.51:1 | 5.53:1 | 4.85:1 | 6.50:1 |
| 暖杏灰 | 14.40:1 | 5.48:1 | 4.85:1 | 6.50:1 |

辅助文字在纸面上最低 4.67:1，满足小字号文本的 4.5:1 要求。

## 预览

- 打开 `Color Study.html`
- 顶部切换三套方案；工具栏切换总览、挂机设置、账号
- 「颜色映射」展开完整色值与组件对应关系
- 「并排比较」同时加载三套配色

设计稿复用当前生产界面的样式与组件，仅新增主题覆盖（`assets/design.css`）与演示数据；没有修改 `desktop/webui` 下的生产代码。
