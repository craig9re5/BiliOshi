# ビリ推し · 品牌与 Logo 规范

给设计组的执行说明。目标是替换当前临时图标，并统一窗口、托盘、安装包和商店素材的视觉。

## 一、产品是什么

ビリ推し（BiliOshi）是 Windows 上的 B 站直播应援助手。

用户关注一批主播，程序在后台替他们完成直播间的日常互动：

- 保持观看心跳，让亲密度按平台规则持续累计；
- 按服务端任务进度补齐弹幕、点赞、观看，完成后自动停止；
- 点亮粉丝牌；
- 在托盘常驻，关闭窗口不打断挂机；
- 账号异常或请求结果不确定时自动暂停，不盲目重试。

用户画像：同时关注多个主播、希望日常任务不占用自己时间的重度观众。他们打开程序的频率很低，多数时间只看托盘图标和偶尔的通知。

## 二、品牌性格

**克制、可靠、安静地陪伴。**

- 不是游戏加速器，不制造紧张感，不用高饱和渐变和发光特效。
- 不是数据面板，不用仪表盘、雷达、芯片、齿轮这类技术隐喻。
- 不做粉丝站的美术，不用偶像照片、应援色或角色形象——程序本身与具体主播无关。
- 情绪是“有人在替我看着”，而不是“很热闹”。

一句话：**后台替你守着推し的那盏灯。**

## 三、名称与文字

| 场景 | 写法 |
| --- | --- |
| 产品名（界面、窗口标题、安装包） | ビリ推し |
| 英文名（仓库、可执行文件、代码） | BiliOshi |
| 组合使用 | ビリ推し（BiliOshi） |
| 不得使用 | 直播助手、BiliOshi 直播助手、A-SOUL、asoul |

名称来源：Bilibili + 推し（oshi，支持的偶像/主播）。日文名是主展示名，英文名用于技术场景。

界面上不出现副标题；品牌区只保留标志和产品名。

## 四、现有视觉基础

设计需与界面一致，颜色和圆角直接复用现有变量：

| 用途 | 值 |
| --- | --- |
| 主色（深青） | `#2d6763` |
| 主色深阶（图标底色起点） | `#1d4a47` → `#0e2225` |
| 暖白背景 | `#faf9f7` |
| 卡片白 | `#ffffff` |
| 侧栏浅灰 | `#f6f5f3` |
| 主文字 | `#253638` |
| 次要文字 | 主文字 62% 不透明度 |
| 圆角 | 图标 16/64，卡片 12，按钮 8 |

字体：Windows 上 `Segoe UI Variable Text` / `Microsoft YaHei UI`；日文名如需排版，使用与之一致的无衬线，不要用装饰字体。

## 五、当前临时图标

现在的图标是代码里用 Pillow 画的“心形 + 心跳线”：

- 深青渐变圆角方块，中间实心心形，心跳线以底色镂空。
- 优点：16 px 可辨认，与心跳机制直接相关。
- 问题：心形 + 心电图的组合过于通用，缺少“推し”和“B 站直播”的识别度，缩小后接近医疗类图标。

设计组可以在保留“心形 / 心跳 / 灯光”任一核心意象的前提下重做，不必沿用当前构图。

## 六、设计方向（三选一或自行提出）

**方向 A：应援灯**
一支被举起的应援灯棒，光晕作为唯一的高光。表达“为推し亮灯”，与点亮粉丝牌的机制呼应。风险是容易做成手电筒，需靠灯头形状和光晕层次区分。

**方向 B：心跳与灯的结合**
心形轮廓内部是灯光的光斑，而不是心电图折线；用光的强弱表达“还在跳”。比当前版本更有品牌感，也更难在小尺寸下保持清晰。

**方向 C：抽象标记**
把“推”的日文假名「推」或「ビ」做几何化处理，形成类似印章的单字标志。识别度最高，但需要处理好日文字形在 16 px 下的笔画丢失。

无论哪个方向，**缩小到 16 px 必须仍然可辨认**，这是硬性验收条件。

## 七、交付要求

| 项目 | 规格 |
| --- | --- |
| 主标志 | SVG，画布 64×64，可无损缩放 |
| 小尺寸版本 | 16 / 24 / 32 px 单独优化，不要直接缩放主标志 |
| Windows 图标 | `.ico`，包含 16、24、32、48、64、128、256 px |
| 托盘图标 | 32 px 为主，需在深色和浅色任务栏都清晰 |
| 单色版 | 纯色剪影，用于托盘和禁用态 |
| 背景 | 透明；如需底色版本，单独提供，不要烘焙进主体 |
| 安全边距 | 四周至少留 12.5%（64 画布即 8 px） |
| 文件命名 | `bilioshi-mark.svg`、`bilioshi-16.png` … `bilioshi.ico` |

色彩可用品牌深青，也可提出一个更鲜明的强调色，但必须同时提供单色版本，并说明在浅色和深色界面中的用法。

## 八、必须避免

- 不使用 B 站官方标志、形象或其近似变体。
- 不使用具体主播、角色、照片或粉丝团素材。
- 不使用渐变发光、玻璃拟态、3D 浮雕等容易过时的效果。
- 不在图标内放文字（“B”“推”以外的汉字、英文单词）。
- 不使用细于 2 px（按 64 画布计）的线条，缩小后会消失。
- 不把产品名排版进图标。

## 九、验收清单

1. 16 px 下轮廓清晰，能一眼与系统托盘其他图标区分。
2. 纯黑白打印仍可识别。
3. 在 `#faf9f7` 和 `#1a1c1e` 两种背景上都成立。
4. 与现有深青主色放在一起不冲突。
5. 不包含任何第三方品牌或角色元素。

## 十、代码中的替换位置

设计定稿后，图标只需替换两处：

- `desktop/widgets.py` 的 `icon_image()`：窗口、托盘和安装包共用的位图来源。
- `desktop/webui/assets/js/icons.jsx` 的 `Pulse`：侧栏品牌区的矢量标记。

其余界面不出现独立标志，因此不需要额外适配。
